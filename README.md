# Snake and Ladder Webapp

This project is still in progress. The main features work locally, and I’m adding more as I learn. Not deployed yet.

A Snake and Ladder game website built with Node.js, React.js, Express.js, and MongoDB. Users can create accounts, play, save, and resume games. Supports up to 4 players and is fully responsive.

## Features

- User accounts with login/logout  
- Save and resume game progress  
- Multiplayer (up to 4 players)  
- Responsive design  
- Secure authentication and data storage  

## Technologies

- Node.js, Express.js  
- React.js  
- MongoDB  
- HTML, CSS, JavaScript  
- TailwindCSS  

## Usage

- Register and log in  
- Start a new game or load saved game  
- Play with up to 4 players  
- Save progress and log out
